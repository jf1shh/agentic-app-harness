# Output (Layer 4)

This stage's real output is `tasks/*.md` at the **repo root** (see `tasks/README.md` for the
contract each work order follows), not in this folder.

Work orders are living files — claimed, worked, pruned by `emit-tasks.mjs --prune` — so a copy
here would immediately diverge from the one agents actually act on. Kept as a pointer for the same
reason as `../../sense/output/README.md`.
