# Output (Layer 4)

This stage's real output is `harness-status.json` at the **repo root**, not in this folder.

It's gitignored and regenerated by `node scripts/harness-status.mjs` on every run — copying it
here would create a second, stale copy the moment either one changed. This file exists so the
stage folder is physically complete per ICM's Layer 4 convention, while the actual artifact keeps
one home. See `_config/conventions.md` for why this repo links instead of duplicating.
